## 📖 About

**ITLEAP PRO** is a modern learning platform built to help developers and IT students master technical interview concepts through smart flashcards, spaced repetition, and timed quizzes. It covers over **2500+ flashcards** spanning **24 IT topics** — from core programming languages to cloud and machine learning fundamentals.

The entire app is **100% client-side** — no backend, no login, no build tools, and zero npm dependencies. All progress, streaks, and bookmarks are stored locally in your browser via `localStorage`, making it fast, private, and offline-friendly.

---

## ✨ Features

- 🃏 **2500+ flashcards** across 24 IT topics
- 🧠 **8-box Leitner spaced repetition** system (1m → 80d intervals)
- ⏱️ **Timed quiz mode** with combo bonuses
- 🔥 Streaks, daily goals, XP, and level progression
- 🔍 Search & filter by keyword, topic, or difficulty
- 🔖 Bookmarks for later revision
- 📊 Progress dashboard (learned, mastered, due, accuracy)
- 📱 Fully responsive with touch/swipe gestures
- 🌙 Dark theme with gradient accents
- 💾 Offline-first with localStorage persistence

## ⚙️ How It Works

### 🔁 Spaced Repetition

Cards move through an **8-box Leitner system**. Correct answers push a card to the next box with a longer review interval (1 minute → 80 days); incorrect answers send it back to box one. This keeps difficult cards in frequent rotation while easy cards fade into longer review cycles.

### 🎯 Quiz Mode

Test your knowledge under time pressure. Consecutive correct answers build a **combo multiplier** for bonus points, while speed and accuracy feed directly into your XP and level progression.
